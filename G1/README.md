| Pasta | Conteúdo |
|---|---|
| `notebooks/` | `PLANT___Experimento_B.ipynb`: processamento completo (Colab) |
| `dados/` | a preencher. Hoje o notebook baixa o `dados.csv` do Google Drive via `gdown` |
| `firmware/` | a preencher com o código das placas ESP + SCD40 |
| `figuras/` | a preencher com as figuras geradas pelo notebook |
| `relatorio/` | a preencher com a fonte LaTeX e o PDF do relatório |

## Como reproduzir

Abra `notebooks/PLANT___Experimento_B.ipynb` no Google Colab e execute tudo. O notebook baixa os dados sozinho.
